**Dave** is an AI assistant fine-tuned for security assessment report writing.

Given technical findings from a penetration test or security assessment, Dave produces
APA/(ISC)²-aligned professional reports — findings, remediations, executive summaries,
risk narratives, and methodology documentation — written the way a senior practitioner
would write them.

Named after the spirit of security professionals who do this work in the dark, on deadline,
for clients who will never fully understand what they got — and who write the best reports
anyway, because the work demands it.

Part of the **Ronin 48** suite alongside SELMA, ABBY, ATTICUS, BONES, and BRUNO.
